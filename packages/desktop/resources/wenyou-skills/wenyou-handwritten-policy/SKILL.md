# 纯手写「抓大放小」国策写作与门禁 SOP

> 署名规范：安钰

## 1. 动笔前先核旧账
1. 务必先调 `wenyou_read_memory` 核实本国在 `01-设定与国力实册/` 的真实财政、兵力、粮草、条约义务与 L1 台账最新态势；严禁脱离实册凭空造兵、造钱或提前引用未来回合事件。
2. 严守阵营信息隔离：站在哪一国写国策，就只能使用该阵营在公开群、本国内阁与已签条约中合理知晓的情报，严禁偷看或暗示 GM 暗线/敌国私密底牌（防超游透题）。

## 2. 「抓大放小」纯手写体文风铁律
- **抓大放小**：每轮国策聚焦 2–4 件真正决定局势的大事（如边防调兵与粮道、关键税制/盐铁整顿、一条核心外交落子），把钱从哪出、兵往哪调、谁来督办、底线退路写实，不为凑字数强行面面俱到。
- **自然段叙述**：采用单居中标题 + 平实自然段或一级序号条陈，不设章节小标题，读起来像真人玩家亲手写的奏疏或军政条陈。
- **三大常见避坑（起草己方国策时工具默认检查）**：
  1. 避免 Markdown 表格（`| 列 | 列 |`）；
  2. 避免多层嵌套清单（二级及以上缩进 bullet/数字列表）；
  3. 避免 AI 模板公文套话（「把规矩立住」「攒下班底」「抓在自己人手里」「大铺摊子」「顶层设计」「组合拳」「赋能」「抓手」；句尾「既……又……。」仅作提醒不硬拦截）。

## 3. 校验、`.docx` 落盘与群友国策原样归档
1. 写完己方初稿后，调用 `wenyou_write_policy_docx({ title, content, actor, turnLabel })`。
2. **闭环自修与强制放行**：起草己方国策遇到门禁违规时先改写自然段重试；若是**原样归档群友国策**或用户明确要求保留原有格式/表格，可直接写入 `03-国策与文书/` 或传 `force: true` 调用 `wenyou_write_policy_docx` 强制落盘。
3. 成功后系统会在 `03-国策与文书/` 产出成对的 `.md` 与宋体五号（10.5pt）、首行缩进 2 字符、1.25 倍行距、居中 15pt 标题的标准 `.docx`（Metadata Creator 固定「安钰」），并在右侧「国策书案」画布自动展示。
